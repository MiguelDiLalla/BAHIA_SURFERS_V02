## 📋 Cloudflare Pages Deployment Steps

### Option 1: Using Cloudflare Dashboard (Recommended)

1. **Login to Cloudflare Dashboard**
   - Go to: https://dash.cloudflare.com/
   - Navigate to: Workers & Pages → Create application → Pages → Connect to Git

2. **Connect Repository** (if using Git)
   - Select your Git provider (GitHub/GitLab/Bitbucket)
   - Authorize Cloudflare
   - Select repository: `BAHIA_SURFERS_V02`
   - Configure build settings:
     - **Build command**: `npm run build:skipCheck`
     - **Build output directory**: `build`
     - **Root directory**: `/` (or leave empty)

3. **Configure Build Settings**
   - Framework preset: **Vite**
   - Node version: **18** or **20**
   - Environment variables: None required (unless you have API keys)

4. **Deploy**
   - Click "Save and Deploy"
   - Wait for build to complete (~2-3 minutes)
   - Your site will be available at: `https://[project-name].pages.dev`

### Option 2: Using Wrangler CLI (Direct Upload)

1. **Install Wrangler** (if not already installed)

   ```bash
   npm install -g wrangler
   ```

2. **Login to Cloudflare**

   ```bash
   wrangler login
   ```

3. **Deploy the build folder**

   ```bash
   cd C:\Users\User\Projects_Unprotected\BAHIA_SURFERS_V02
   wrangler pages deploy build --project-name=bahia-surfers-radio
   ```

4. **Follow prompts**
   - Confirm project name
   - Wait for upload to complete
   - Site will be live at: `https://bahia-surfers-radio.pages.dev`

### Option 3: Drag and Drop (Simplest)

1. **Go to Cloudflare Dashboard**
   - Navigate to: Workers & Pages → Create application → Pages → Upload assets

2. **Upload the build folder**
   - Drag the entire `build/` folder contents
   - Or click to browse and select all files in `build/`

3. **Configure project**
   - Project name: `bahia-surfers-radio`
   - Production branch: `main` (or your branch name)

4. **Deploy**
   - Click "Deploy site"
   - Your site will be live instantly

## 🔍 Troubleshooting

### Build Fails on Cloudflare

- **Issue**: TypeScript errors during build
- **Solution**: Use `build:skipCheck` command instead of `build`
- **In Cloudflare settings**: Change build command to `npm run build:skipCheck`

### Service Worker Not Registering

- **Issue**: PWA features not working
- **Solution**: Ensure HTTPS is enabled (Cloudflare does this automatically)
- **Check**: Browser DevTools → Application → Service Workers

### Icons Not Displaying

- **Issue**: Font Awesome icons missing
- **Solution**: Verify CDN is accessible (should be, Cloudflare CDN is reliable)
- **Check**: Browser DevTools → Network tab for failed requests

### CORS Issues with Radio Stream

- **Issue**: Audio stream won't play
- **Solution**: Verify `crossOrigin="anonymous"` is set on `<audio>` tag (already done)
- **Check**: The radio server must have proper CORS headers

### Custom Domain SSL Issues

- **Issue**: SSL certificate not provisioning
- **Solution**: Wait 24 hours for DNS propagation
- **Alternative**: Use Cloudflare's flexible SSL mode temporarily
